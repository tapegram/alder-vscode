# Scratch files Implementation Plan (alder#144 milestone 6)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `Alder: Open Scratch`, `Alder: Send to Scratch` and `Alder: Open Scratch Value` work, a scratch file's file-level error or note shows on its first line, and a hover shows a watch's value when the server's inlay hint cannot show all of it. It ports alder.nvim's `scratch.lua`.

**Architecture:** The values themselves are the server's inlay hints (`inlayHintReq` in `internal/lsp/scratchview.go`); the stock client already shows them. Two pure modules (no `vscode` import) carry the logic: `scratchText.ts` (the send side: the template, `isDefinition`, the appended text, the `in Module` warning) and `scratch.ts` (the store of the last `alder/scratch` per URI with a snapshot of the document's lines, the watch under a line, the texts shown). `scratchUi.ts` is the thin VS Code side: three commands, a hover provider, and one decoration on line 1. `client.ts` takes the snapshot when the notification arrives.

**Tech Stack:** TypeScript 5.9, VS Code API ^1.91 (`@types/vscode` 1.91.0), vscode-languageclient 11, node:test (unit), mocha + @vscode/test-electron (e2e), esbuild.

**Spec:** tapegram/alder `docs/superpowers/specs/2026-11-01-vscode-extension-design.md`, section "Scratch files (`src/scratch.ts`)", "Extension tests" (the scratch bullet) and milestone 6. To read it: `git -C ~/projects/alder show origin/main:docs/superpowers/specs/2026-11-01-vscode-extension-design.md`. The nvim original is `~/projects/alder.nvim/lua/alder/scratch.lua`, its spec `~/projects/alder.nvim/tests/scratch_spec.lua`. The server side: `~/projects/alder/internal/lsp/scratch.go` (the notification), `scratchview.go` (`inlayHintReq`, `hintLabel`), `protocol.go` (`scratchParams`), `internal/scratch/filerun.go` (`WatchResult`, the notes).

## Global Constraints

- `engines.vscode` stays `^1.91.0`. No proposed API.
- No new runtime or dev dependencies.
- `src/scratch.ts` and `src/scratchText.ts` must not import `vscode`.
- Never reword the compiler: the server's `error`, `note`, `warning` and watch texts are shown as sent (only cut to their first line where a single line is shown).
- A scratch file is any file whose base name ends in `scratch.alder` (`syntax.IsScratchName`). `Alder: Open Scratch` and `Send to Scratch` use `<root>/scratch.alder`.
- Message strings (exact):
  - `alder: no scratch value here` (information, Open Scratch Value with no watch under the cursor);
  - `alder: open a file to send from` (information, Send with no active editor);
  - `alder: scratch.alder is not "in <M>"; names from <M> need qualifying (add "in <M>" as its first line)` (warning, once per window session);
  - `alder: could not create <path>: <message>`, `alder: could not edit <path>`, `alder: could not save <path>` (errors);
  - `NO_ROOT` from `src/project.ts` when the active file has no app root.
- The template is the text of alder's `internal/scaffold/files/scratch.alder`, byte for byte (Task 1 copies it).
- The deviations from the spec this plan makes on purpose (list them in the PR):
  1. The value document uses the existing `alder-doc` scheme through `VirtualDocs` (path `scratch/value.txt`), not an `alder-scratch:` scheme, as M5 did for its previews.
  2. The watch text shows a note as well as a value (`<Task>` and then the effect note), where nvim's open_value shows the value alone. The server's inlay hint never shows a note, so this is the only place it appears.
  3. A file-level `warning` stays for both phases of the run that first sent it (nvim's shows only during the `types` phase and is dropped by the `values` one).
  4. `Open Scratch Value` and the hover find the watch by comparing the document's lines with the lines at the time of the run (the rule the server's inlay hints use), not by marks that follow edits. A watch whose lines moved or changed since the run has no value until the next run.
- Each commit ends with the attribution lines from the session's system reminder.
- Branch: `scratch` off `main` in `~/projects/alder-vscode` (already created).
- Unit: `npm run test:unit`. E2e: `ALDER_BIN=$(go env GOPATH)/bin/alder ALDER_REPO=~/projects/alder npm run test:e2e`. Run one file with `ALDER_E2E_ONLY=scratch` (a file-name prefix: see `test/e2e/index.ts`). Lint: `npm run lint`.
- Local e2e is unreliable when the machine is loaded. On an e2e failure, check `uptime` first. When the load is above 50, rerun once before you debug.

## Review Focus

1. **A scratch file saved with CRLF line endings.** The send must still add exactly one blank separator line, and must not treat `\r` as content. Task 1 pins this: `a CRLF file gets one separator`.
2. **A notification for a version the editor has already moved past** (the user typed while the run was going). There is no snapshot, so Open Scratch Value says there is nothing here rather than showing a value for the wrong lines, and the line-1 note is dimmed. Task 2 pins this: `no snapshot, no watch`; Task 4 pins the dimming through `line(uri).stale`.
3. **Lines inserted above a watch after the run.** The watch must not be found at its old line number. Task 2 pins this: `a changed or moved watch is not found`.
4. **The scratch document is open with unsaved edits when something is sent to it.** The send appends to the document (not to the file on disk), and the save keeps both the user's edits and the new watch. Task 3 pins this: e2e `send keeps unsaved edits in the scratch document`.
5. **A selection that ends at column 0 of the next line** (a full-line selection made with the mouse or shift+down). That last line is not sent. Task 1 pins this: `lineSpan drops a last line selected only up to column 0`.

```ts
// The send side of scratch files, ported from alder.nvim's scratch.lua: no vscode import.

export const SCRATCH_FILE = 'scratch.alder';

// TEMPLATE is the text of a new scratch.alder (internal/scaffold/files/scratch.alder in alder).
export const TEMPLATE = [
  '-- A scratch file: each `> expr` line is evaluated. Run `alder scratch --watch` to see results on save.',
  '-- Everything else is ordinary Alder: define values and helpers here, then watch them.',
  '-- Put `in Module` on the first line to work inside an app module, with its names unqualified.',
  '',
  '> 1 + 1',
  '',
].join('\n');

// isScratchPath is whether path names a scratch file (syntax.IsScratchName): its base name ends
// in scratch.alder.
export function isScratchPath(path: string): boolean {
  const base = path.split(/[\\/]/).pop() ?? '';
  return base.endsWith(SCRATCH_FILE);
}

const DEFINITION_KEYWORDS = ['type', 'alias', 'import', 'page', 'msg', 'form', 'table', 'capability', 'fake', 'session', 'login', 'test'];
const EXPRESSION_KEYWORDS = new Set(['let', 'if', 'case']);

// isDefinition says whether a line starts a definition rather than an expression: it begins with
// a declaration keyword and the start of its head (`type Model`, `page "/x"`, `session {`), or is
// a signature (`name :`), or is a binding (`f x =`, not `==`/`<=`).
export function isDefinition(line: string): boolean {
  line = line.replace(/^\s+/, '');
  for (const kw of DEFINITION_KEYWORDS) {
    if (new RegExp(`^${kw}\\s+[A-Z"{]`).test(line)) return true;
  }
  if (/^[A-Za-z_][A-Za-z0-9_']*\s*:/.test(line)) return true;
  const word = /^[a-z_][A-Za-z0-9_']*/.exec(line)?.[0];
  if (!word || EXPRESSION_KEYWORDS.has(word)) return false;
  const eq = line.indexOf('=');
  if (eq < 0 || line[eq + 1] === '=') return false;
  return /^[A-Za-z0-9_'\s(),{}:]*$/.test(line.slice(0, eq));
}

const blank = (l: string) => !/\S/.test(l);

// scratchInsert is the text to add at the end of a scratch document whose text is text, to send
// lines to it; undefined when they are all blank. A definition, or lines that already hold
// watches (raw), go in as written; an expression becomes a `> ` watch with its other lines
// indented four spaces. Leading `--` comments go in as written either way. One blank line
// separates it from what is there, unless the file already ends in one.
export function scratchInsert(text: string, lines: string[], raw: boolean): string | undefined {
  let indent: number | undefined;
  for (const l of lines) {
    if (blank(l)) continue;
    const n = /^\s*/.exec(l)![0].length;
    indent = indent === undefined ? n : Math.min(indent, n);
  }
  const out = lines.map(l => (raw ? l : l.slice(indent ?? 0)));
  while (out.length > 0 && blank(out[0])) out.shift();
  while (out.length > 0 && blank(out[out.length - 1])) out.pop();
  if (out.length === 0) return undefined;
  const add: string[] = [];
  if (raw) {
    add.push(...out);
  } else {
    let first = 0;
    while (first < out.length && (out[first].startsWith('--') || blank(out[first]))) add.push(out[first++]);
    if (first < out.length && isDefinition(out[first])) {
      add.push(...out.slice(first));
    } else if (first < out.length) {
      add.push('> ' + out[first]);
      for (const l of out.slice(first + 1)) add.push(l === '' ? '' : '    ' + l);
    }
  }
  const t = text.replace(/\r\n/g, '\n');
  const ended = t === '' || t.endsWith('\n');
  const existing = t === '' ? [] : (ended ? t.slice(0, -1) : t).split('\n');
  const lastBlank = existing.length > 0 && existing[existing.length - 1] === '';
  const sep = existing.length === 0 || lastBlank ? '' : '\n';
  return (ended ? '' : '\n') + sep + add.join('\n') + '\n';
}

// lineSpan is the first and last line of a selection (0-based); a last line selected only up
// to its column 0 is not part of it.
export function lineSpan(start: { line: number; character: number }, end: { line: number; character: number }): [number, number] {
  const last = end.line > start.line && end.character === 0 ? end.line - 1 : end.line;
  return [start.line, last];
}

// moduleName is the name on the first `module` line (buf.lua's fallback; there is no tree-sitter
// here).
export function moduleName(text: string): string | undefined {
  return /^module\s+([A-Za-z0-9_.]+)/m.exec(text)?.[1];
}

// headerModule is the module named by a scratch file's `in` header (its first line of code).
export function headerModule(text: string): string | undefined {
  for (const l of text.split(/\r?\n/)) {
    if (blank(l) || /^\s*--/.test(l)) continue;
    return /^in\s+([A-Za-z0-9.]+)\s*$/.exec(l)?.[1];
  }
  return undefined;
}

// inHeaderWarning is the warning for sending from module to a scratch file that is not `in` it.
export function inHeaderWarning(module: string | undefined, scratchText: string): string | undefined {
  if (!module || headerModule(scratchText) === module) return undefined;
  return `alder: scratch.alder is not "in ${module}"; names from ${module} need qualifying (add "in ${module}" as its first line)`;
}
```

```ts
// The alder/scratch notification: the server's last run of a scratch file, and what the editor
// shows of it. The values themselves are the server's inlay hints; this is what hints cannot
// carry (the full value, a file-level error or note). No vscode import.

// ScratchWatch is internal/scratch's WatchResult.
export interface ScratchWatch {
  line: number;
  end?: number; // the watch's last line (line for a one-line watch)
  expr?: string;
  value?: string;
  type?: string;
  error?: string;
  note?: string;
  kind?: string;
  truncated?: boolean;
}

// ScratchParams are internal/lsp's scratchParams: "types" once the file has checked, then
// "values" when the run ends.
export interface ScratchParams {
  uri: string;
  version?: number;
  phase?: string;
  ran?: boolean;
  watches?: ScratchWatch[];
  error?: string;
  note?: string;
  warning?: string;
}

// ScratchEntry is a notification and the document's lines at its version, when the editor still
// had that version as it arrived (else none: no watch can be found until the next run).
export interface ScratchEntry {
  params: ScratchParams;
  lines?: string[];
}

export class ScratchStore {
  private byUri = new Map<string, ScratchEntry>();
  private listeners = new Set<(uri: string) => void>();

  record(p: ScratchParams, lines?: string[]): void {
    if (!p || typeof p.uri !== 'string') return;
    this.byUri.set(p.uri, { params: p, lines });
    this.fire(p.uri);
  }

  last(uri: string): ScratchParams | undefined {
    return this.byUri.get(uri)?.params;
  }

  entry(uri: string): ScratchEntry | undefined {
    return this.byUri.get(uri);
  }

  forget(uri: string): void {
    if (this.byUri.delete(uri)) this.fire(uri);
  }

  clear(): void {
    const uris = [...this.byUri.keys()];
    this.byUri.clear();
    for (const u of uris) this.fire(u);
  }

  // onChange calls f with the uri of each record, forget and clear; the result unsubscribes.
  onChange(f: (uri: string) => void): () => void {
    this.listeners.add(f);
    return () => this.listeners.delete(f);
  }

  private fire(uri: string): void {
    for (const f of this.listeners) f(uri);
  }
}

// docLines splits a document's text into lines, LF or CRLF.
export function docLines(text: string): string[] {
  return text.split(/\r?\n/);
}

// watchAt is the watch whose lines hold line (1-based) in a document whose lines are now, when
// those lines are as they were at the run (the rule of the server's inlay hints).
export function watchAt(e: ScratchEntry, now: string[], line: number): ScratchWatch | undefined {
  const then = e.lines;
  if (!then) return undefined;
  for (const w of e.params.watches ?? []) {
    const end = w.end ?? w.line;
    if (line < w.line || line > end || w.line < 1 || end > now.length || end > then.length) continue;
    let same = true;
    for (let i = w.line - 1; i < end; i++) if (now[i] !== then[i]) same = false;
    if (same) return w;
  }
  return undefined;
}

// watchText is a watch's full result: the error, else the value and the note, then `: Type`.
export function watchText(w: ScratchWatch): string {
  const parts = w.error ? [w.error] : [w.value, w.note].filter((s): s is string => !!s);
  if (w.type) parts.push(': ' + w.type);
  return parts.join('\n');
}

// MAX_HINT is the server's cap on an inlay hint's label, in code points (maxHint).
export const MAX_HINT = 120;

// fullHint is the server's hintLabel before its cap: what the inlay hint shows.
export function fullHint(w: ScratchWatch): string {
  const first = (s: string) => s.split('\n')[0];
  if (w.error) return '✗ ' + first(w.error);
  if (w.value) {
    let l = first(w.value);
    if (l !== w.value || w.truncated) l += ' …';
    return '⇒ ' + l + (w.type ? ' : ' + w.type : '');
  }
  if (w.type) return ': ' + w.type;
  return '';
}

// needsHover is whether the inlay hint leaves part of a watch out: a multi-line or cut value or
// error, a label over the cap, or a note (which hints never show).
export function needsHover(w: ScratchWatch): boolean {
  if (w.note || w.truncated) return true;
  if ((w.error || w.value || '').includes('\n')) return true;
  return [...fullHint(w)].length > MAX_HINT;
}

// FileLine is the file-level text on a scratch document's first line.
export interface FileLine {
  text: string;
  kind: 'error' | 'note';
  warning: boolean; // it is the warning: the caller records warnedAt = p.version
}

// fileLine is the first line of p's error, else its note, else its warning when no other run
// has shown it (warnedAt is the version of the run that first showed it, or undefined).
export function fileLine(p: ScratchParams, warnedAt: number | undefined): FileLine | undefined {
  const first = (s: string) => s.split('\n')[0];
  if (p.error) return { text: first(p.error), kind: 'error', warning: false };
  if (p.note) return { text: first(p.note), kind: 'note', warning: false };
  if (p.warning && (warnedAt === undefined || warnedAt === p.version)) return { text: first(p.warning), kind: 'note', warning: true };
  return undefined;
}
```

```ts
import { writeFile } from 'node:fs/promises';
import { join } from 'node:path';
import * as vscode from 'vscode';
import type { Deps } from './deps';
import { NO_ROOT, requireRoot } from './project';
import { findRoot } from './root';
import { inHeaderWarning, isScratchPath, lineSpan, moduleName, SCRATCH_FILE, scratchInsert, TEMPLATE } from './scratchText';

export const NO_EDITOR = 'alder: open a file to send from';

// ScratchUi is scratch.lua's editor side: Open Scratch, Send to Scratch, Open Scratch Value, the
// hover and the file-level line. The values themselves are the server's inlay hints.
export class ScratchUi {
  private warnedIn = false; // the `in Module` warning, once per session

  constructor(private readonly deps: Deps) {}

  register(context: vscode.ExtensionContext): void {
    context.subscriptions.push(
      vscode.commands.registerCommand('alder.scratch.open', () => this.open()),
      vscode.commands.registerCommand('alder.scratch.send', () => this.send()),
    );
  }

  // open shows <root>/scratch.alder of the project, creating it from TEMPLATE when missing.
  async open(): Promise<vscode.TextEditor | undefined> {
    const root = await requireRoot(this.deps.clients);
    if (!root) return undefined;
    const path = await ensure(root);
    return path ? vscode.window.showTextDocument(vscode.Uri.file(path)) : undefined;
  }

  // send appends the selected lines (or the cursor's line) of the active editor to its app's
  // scratch.alder and saves it, which runs it; a definition goes in as written, an expression as
  // a watch, and lines in a scratch file that already hold watches as they are.
  async send(): Promise<boolean> {
    const editor = vscode.window.activeTextEditor;
    if (!editor) {
      void vscode.window.showInformationMessage(NO_EDITOR);
      return false;
    }
    const from = editor.document;
    const root = from.uri.scheme === 'file' ? await findRoot(from.uri.fsPath) : undefined;
    if (!root) {
      void vscode.window.showErrorMessage(NO_ROOT);
      return false;
    }
    const [first, last] = lineSpan(editor.selection.start, editor.selection.end);
    const lines: string[] = [];
    for (let i = first; i <= last; i++) lines.push(from.lineAt(i).text);
    const fromScratch = isScratchPath(from.uri.fsPath);
    const raw = fromScratch && lines.some(l => l.startsWith('>'));
    const module = !fromScratch && from.languageId === 'alder' ? moduleName(from.getText()) : undefined;
    const path = await ensure(root);
    if (!path) return false;
    const target = await vscode.workspace.openTextDocument(vscode.Uri.file(path));
    const insert = scratchInsert(target.getText(), lines, raw);
    if (insert === undefined) return false;
    const edit = new vscode.WorkspaceEdit();
    edit.insert(target.uri, target.lineAt(target.lineCount - 1).range.end, insert);
    if (!(await vscode.workspace.applyEdit(edit))) {
      void vscode.window.showErrorMessage(`alder: could not edit ${path}`);
      return false;
    }
    if (!(await target.save())) {
      void vscode.window.showErrorMessage(`alder: could not save ${path}`);
      return false;
    }
    if (!vscode.window.visibleTextEditors.some(e => e.document === target)) {
      await vscode.window.showTextDocument(target, { viewColumn: vscode.ViewColumn.Beside, preserveFocus: true });
    }
    const warning = this.warnedIn ? undefined : inHeaderWarning(module, target.getText());
    if (warning) {
      this.warnedIn = true;
      void vscode.window.showWarningMessage(warning);
    }
    return true;
  }
}

// ensure is <root>/scratch.alder, written from TEMPLATE first when it is missing; undefined
// (reported) when it cannot be written.
async function ensure(root: string): Promise<string | undefined> {
  const path = join(root, SCRATCH_FILE);
  try {
    await writeFile(path, TEMPLATE, { flag: 'wx' });
  } catch (err) {
    if ((err as NodeJS.ErrnoException).code !== 'EEXIST') {
      void vscode.window.showErrorMessage(`alder: could not create ${path}: ${err instanceof Error ? err.message : String(err)}`);
      return undefined;
    }
  }
  return path;
}
```

```ts
  // openValue opens the full result of the watch under the cursor in a read-only document beside.
  async openValue(): Promise<vscode.TextDocument | undefined> {
    const editor = vscode.window.activeTextEditor;
    const w = editor && this.watchAt(editor.document, editor.selection.active.line + 1);
    if (!w) {
      void vscode.window.showInformationMessage(NO_VALUE);
      return undefined;
    }
    const uri = this.deps.docs.set('scratch/value.txt', watchText(w));
    const doc = await vscode.workspace.openTextDocument(uri);
    await vscode.window.showTextDocument(doc, { viewColumn: vscode.ViewColumn.Beside, preserveFocus: true, preview: true });
    return doc;
  }

  // line is what line 1 of the scratch document uri shows, for the tests.
  line(uri: string): { text: string; kind: 'error' | 'note'; stale: boolean } | undefined {
    const l = this.shown.get(uri);
    const doc = vscode.workspace.textDocuments.find(d => d.uri.toString() === uri);
    if (!l || !doc) return undefined;
    return { text: l.text, kind: l.kind, stale: this.stale(uri, doc) };
  }

  private watchAt(doc: vscode.TextDocument, line: number): ScratchWatch | undefined {
    const e = this.deps.clients.scratch.entry(doc.uri.toString());
    return e && watchAt(e, docLines(doc.getText()), line);
  }

  private stale(uri: string, doc: vscode.TextDocument): boolean {
    return this.deps.clients.scratch.last(uri)?.version !== doc.version;
  }

  // recorded computes the file-level line of a new notification (or its absence) and paints it.
  private recorded(uri: string): void {
    const p = this.deps.clients.scratch.last(uri);
    const l = p && fileLine(p, this.warnedAt.get(uri));
    if (l?.warning && !this.warnedAt.has(uri) && p?.version !== undefined) this.warnedAt.set(uri, p.version);
    if (l) this.shown.set(uri, l);
    else this.shown.delete(uri);
    this.paint(uri);
  }

  // paint puts the file-level line at the end of line 1 in every editor showing uri, dimmed when
  // the document has changed since the run.
  private paint(uri: string): void {
    const l = this.shown.get(uri);
    for (const editor of vscode.window.visibleTextEditors) {
      if (editor.document.uri.toString() !== uri) continue;
      if (!l) {
        editor.setDecorations(this.deco, []);
        continue;
      }
      const color = this.stale(uri, editor.document) ? 'disabledForeground' : l.kind === 'error' ? 'errorForeground' : 'editorInlayHint.foreground';
      const end = editor.document.lineAt(0).range.end;
      editor.setDecorations(this.deco, [{
        range: new vscode.Range(end, end),
        renderOptions: { after: { contentText: '  ' + l.text, color: new vscode.ThemeColor(color) } },
      }]);
    }
  }
```
