# Release Implementation Plan (alder#144 milestone 7)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** alder-vscode 0.1.0 can be released by pushing a tag. The tag runs the full CI, then a GitHub release is created with the checked `.vsix` and the CHANGELOG's notes for that version. The README covers install, requirements and what fill sends. Before the release, a dogfooding pass runs the extension against nightvote-replay, a real app, and records what it found.

**Architecture:** A pure script, `scripts/release.ts`, holds the release rules. It checks the tag against the package version, cuts the CHANGELOG section, and checks the `.vsix`'s file list and its bundle's `require`s. It is unit-tested and is the only logic in the workflows. `ci.yml` becomes reusable (`workflow_call`) and checks the `.vsix` it packages. A new `release.yml` runs on `v*` tags: it calls `ci.yml`, then packages and creates the release. The dogfood pass is an opt-in e2e file (`dogfood.e2e.ts`) that `run.ts` launches only when `ALDER_DOGFOOD_ROOT` is set. It runs on a copy of that app and writes a JSON report.

**Tech Stack:** TypeScript 5.9, node:test, GitHub Actions, `@vscode/vsce` 4, `unzip` (on both runner images and macOS), mocha + @vscode/test-electron.

**Spec:** tapegram/alder `docs/superpowers/specs/2026-11-01-vscode-extension-design.md`: sections "Packaging", "Goals" item 5 and milestone 7. To read it: `git -C ~/projects/alder show origin/main:docs/superpowers/specs/2026-11-01-vscode-extension-design.md`. alder.nvim has no release workflow to copy.

- The bundle `dist/extension.js` may `require` only `vscode` and Node built-ins (`node:` prefixed or in `module.builtinModules`).

- Unit: `npm run test:unit`. E2e: `ALDER_BIN=$(go env GOPATH)/bin/alder ALDER_REPO=~/projects/alder npm run test:e2e` (one file: `ALDER_E2E_ONLY=<prefix>`). Lint: `npm run lint`.

## Review Focus

1. **A tag that does not match `package.json`** (`v0.1.0` pushed while the package still says `0.0.1`, or a tag without the `v`). The release job must fail before anything is created. Task 1 pins this: `tagVersion refuses a mismatched or v-less tag`.
2. **A CHANGELOG with no section for the version, or an empty one**, including a near miss: `## 0.1.0-rc.1` or `## 0.1.01` must not count as `## 0.1.0`. The job must fail rather than publish a release with empty or wrong notes. Task 1 pins this: `releaseNotes refuses a missing, empty or prefix-matching section`.
3. **A `.vsix` that grew or lost a file**: `node_modules/`, a source map, `src/` or `test/` slipping in through `.vscodeignore`, or `dist/extension.js` missing. CI must fail on the push that caused it, not on the tag. Task 1 pins this: `vsixProblems names missing and unexpected entries`. Task 2 runs the check in CI.
4. **A bundle that `require`s a package**, such as `vscode-languageclient` marked external by mistake. The extension would install and then fail to activate. Task 1 pins this: `bundleProblems refuses a non-builtin require`.
5. **The dogfood pass touching the real app** (scratch.alder created, a generator applied, a build dir written). Task 4 pins this: `run.ts` compares `git status --porcelain` of the dogfood root before and after, and fails if it changed.

```ts
// The release rules, pure, plus a small CLI the workflows run (after `tsc -p .`):
//   node out/scripts/release.js notes <tag>        the CHANGELOG section for the tag's version
//   node out/scripts/release.js check-vsix <file>  the .vsix's entries and its bundle's requires
import { execFileSync } from 'node:child_process';
import { readFileSync } from 'node:fs';
import { builtinModules } from 'node:module';
import { join } from 'node:path';

// EXPECTED_VSIX is every file `vsce package` puts in the .vsix (pinned 2026-11-04, vsce 4).
// A change to .vscodeignore or package.json's files changes this list on purpose.
export const EXPECTED_VSIX = [
  '[Content_Types].xml',
  'extension.vsixmanifest',
  'extension/LICENSE.txt',
  'extension/changelog.md',
  'extension/dist/extension.js',
  'extension/language-configuration.json',
  'extension/package.json',
  'extension/readme.md',
  'extension/syntaxes/alder.tmLanguage.json',
];

// tagVersion is the version a tag names: "v<version>" (or refs/tags/v<version>), equal to the
// package's version.
export function tagVersion(tag: string, pkgVersion: string): string {
  const name = tag.replace(/^refs\/tags\//, '');
  if (!name.startsWith('v')) throw new Error(`tag ${name} is not v<version>`);
  const v = name.slice(1);
  if (v !== pkgVersion) throw new Error(`tag ${name} does not match package.json version ${pkgVersion}`);
  return v;
}

// releaseNotes is the body of the "## <version>" section (the heading may go on with a space and
// more, such as a date), up to the next "## " heading, trimmed.
export function releaseNotes(changelog: string, version: string): string {
  const lines = changelog.replace(/\r\n/g, '\n').split('\n');
  const start = lines.findIndex(l => l === `## ${version}` || l.startsWith(`## ${version} `));
  if (start < 0) throw new Error(`CHANGELOG.md has no "## ${version}" section`);
  let end = lines.findIndex((l, i) => i > start && l.startsWith('## '));
  if (end < 0) end = lines.length;
  const body = lines.slice(start + 1, end).join('\n').trim();
  if (!body) throw new Error(`CHANGELOG.md's "## ${version}" section is empty`);
  return body;
}

// vsixProblems compares a .vsix's file entries (directory entries ignored) with EXPECTED_VSIX.
export function vsixProblems(entries: string[]): string[] {
  const got = new Set(entries.filter(e => !e.endsWith('/')));
  const want = new Set(EXPECTED_VSIX);
  return [
    ...EXPECTED_VSIX.filter(e => !got.has(e)).map(e => `missing from the .vsix: ${e}`),
    ...[...got].filter(e => !want.has(e)).sort().map(e => `unexpected in the .vsix: ${e}`),
  ];
}

// bundleRequires is every module the bundle requires by a string literal, once each, sorted.
export function bundleRequires(js: string): string[] {
  const names = new Set<string>();
  for (const m of js.matchAll(/require\((["'])([^"']+)\1\)/g)) names.add(m[2]);
  return [...names].sort();
}

// bundleProblems refuses any require but vscode and Node's built-ins: the .vsix ships no
// node_modules (vsce package --no-dependencies), so anything else fails at activation.
export function bundleProblems(requires: string[]): string[] {
  const builtin = new Set(builtinModules);
  return requires
    .filter(r => r !== 'vscode' && !r.startsWith('node:') && !builtin.has(r))
    .map(r => `the bundle requires ${r} (not vscode or a Node built-in): bundle it or drop it`);
}

function main(argv: string[]): number {
  const [cmd, arg] = argv;
  const root = join(__dirname, '..', '..');
  try {
    if (cmd === 'notes' && arg) {
      const pkg = JSON.parse(readFileSync(join(root, 'package.json'), 'utf8')) as { version: string };
      const v = tagVersion(arg, pkg.version);
      process.stdout.write(releaseNotes(readFileSync(join(root, 'CHANGELOG.md'), 'utf8'), v) + '\n');
      return 0;
    }
    if (cmd === 'check-vsix' && arg) {
      const entries = execFileSync('unzip', ['-Z1', arg], { encoding: 'utf8' }).split('\n').filter(Boolean);
      const problems = vsixProblems(entries);
      if (entries.includes('extension/dist/extension.js')) {
        const js = execFileSync('unzip', ['-p', arg, 'extension/dist/extension.js'], { encoding: 'utf8', maxBuffer: 64 << 20 });
        problems.push(...bundleProblems(bundleRequires(js)));
      }
      for (const p of problems) process.stderr.write(p + '\n');
      return problems.length ? 1 : 0;
    }
    process.stderr.write('usage: release.js notes <tag> | check-vsix <file.vsix>\n');
    return 2;
  } catch (e) {
    process.stderr.write(`${(e as Error).message}\n`);
    return 1;
  }
}

if (require.main === module) process.exitCode = main(process.argv.slice(2));
```

```ts
// dogfood runs dogfood.e2e.ts alone on a copy of a real app (ALDER_DOGFOOD_ROOT), and fails if
// the real app's git status changed: the pass must never write to it.
async function dogfood(src: string): Promise<void> {
  const bin = need('ALDER_BIN');
  const status = () => execFileSync('git', ['status', '--porcelain'], { cwd: src, encoding: 'utf8' });
  const before = status();
  // no [x] in this path: a scratch build of a real app needs its migrations (alder#172)
  const ws = realpathSync(mkdtempSync(join(tmpdir(), 'alder-vscode-dogfood-')));
  const app = join(ws, basename(src));
  cpSync(src, app, {
    recursive: true,
    filter: p => {
      const rel = p.slice(src.length);
      return !/[/\\](\.git|build|node_modules|\.superpowers)([/\\]|$)/.test(rel) && !/\.db(-wal|-shm)?$/.test(rel);
    },
  });
  // Open Scratch must create it, as for a new user
  rmSync(join(app, 'scratch.alder'), { force: true });
  mkdirSync(join(ws, '.vscode'));
  writeFileSync(join(ws, '.vscode/settings.json'), JSON.stringify({
    'alder.path': bin,
    'security.workspace.trust.enabled': false,
    'chat.disableAIFeatures': true,
  }, null, 2));
  const root = resolve(__dirname, '../../..');
  try {
    await runTests({
```

```ts
import * as assert from 'node:assert/strict';
import { execFileSync, spawnSync } from 'node:child_process';
import { mkdirSync, readdirSync, readFileSync, writeFileSync } from 'node:fs';
import { dirname, join, relative } from 'node:path';
import * as vscode from 'vscode';
import { api, decode, until } from './helpers';

const app = process.env.ALDER_DOGFOOD_APP;

interface FileReport { file: string; tokensMs: number; tokens: number; folds: number }
interface Report {
  app: string; alder: string; vscode: string; health: string[];
  check: { exit: number | null; out: string };
  files: FileReport[];
  errors: string[];          // alder Error diagnostics after the settle: "file:line: message"
  routes: { lsp: number | string; cli: number | string };
  tests: { discovered: number; results: number; failed: string[]; outcome: string };
  generators: { file: string; count: number; here: number } | string;
  scratch: { ms: number; hints: string[] } | string;
  failures: string[];        // what the pass treats as broken
}

function alderFiles(dir: string): string[] {
  return readdirSync(dir, { withFileTypes: true }).flatMap(e => {
    const p = join(dir, e.name);
    return e.isDirectory() ? alderFiles(p) : e.name.endsWith('.alder') ? [p] : [];
  }).sort();
}

describe('dogfood', function () {
  this.timeout(1_800_000);
  before(function () { if (!app) this.skip(); });

  it('runs the extension over a real app and writes the report', async () => {
    const root = app!;
    const bin = process.env.ALDER_DOGFOOD_BIN!;
    const a = await api();
    const r: Report = {
      app: root, alder: execFileSync(bin, ['version'], { encoding: 'utf8' }).trim(), vscode: vscode.version,
      health: [], check: { exit: null, out: '' }, files: [], errors: [],
      routes: { lsp: 0, cli: 0 }, tests: { discovered: 0, results: 0, failed: [], outcome: '' },
      generators: '', scratch: '', failures: [],
    };
    const soft = async (what: string, f: () => Promise<void>) => {
      try { await f(); } catch (e) { r.failures.push(`${what}: ${(e as Error).message}`); }
    };

    const chk = spawnSync(bin, ['check'], { cwd: root, encoding: 'utf8' });
    r.check = { exit: chk.status, out: (chk.stdout + chk.stderr).trim().split('\n').slice(0, 20).join('\n') };

    // every file: open, time to the first non-empty tokens, folding ranges
    for (const f of alderFiles(join(root, 'app'))) {
      await soft(relative(root, f), async () => {
        const doc = await vscode.workspace.openTextDocument(vscode.Uri.file(f));
        await vscode.window.showTextDocument(doc, { preview: false });
        await until(async () => a.clients.ensure(doc), 'a client', 60_000);
        const t0 = Date.now();
        const legend = await vscode.commands.executeCommand<vscode.SemanticTokensLegend>('vscode.provideDocumentSemanticTokensLegend', doc.uri);
        const toks = await until(async () => {
          const s = await vscode.commands.executeCommand<vscode.SemanticTokens>('vscode.provideDocumentSemanticTokens', doc.uri);
          return s && s.data.length > 0 ? s : undefined;
        }, 'tokens', 60_000);
        const folds = await vscode.commands.executeCommand<vscode.FoldingRange[]>('vscode.executeFoldingRangeProvider', doc.uri);
        r.files.push({ file: relative(root, f), tokensMs: Date.now() - t0, tokens: decode(toks.data, legend).length, folds: folds?.length ?? 0 });
      });
    }
    r.health = await a.health();

    // diagnostics after the server has had time to build the whole app
    await new Promise(res => setTimeout(res, 10_000));
    for (const [uri, ds] of vscode.languages.getDiagnostics()) {
      for (const d of ds) {
        if (d.source === 'alder' && d.severity === vscode.DiagnosticSeverity.Error) {
          r.errors.push(`${relative(root, uri.fsPath)}:${d.range.start.line + 1}: ${d.message.split('\n')[0]}`);
        }
      }
    }
    if (r.check.exit === 0 && r.errors.length) r.failures.push(`alder check passes but the editor shows ${r.errors.length} errors`);
    if (r.check.exit !== 0 && !r.errors.length) r.failures.push('alder check fails but the editor shows no errors');

    await soft('routes', async () => {
      const lsp = await until(async () => { const g = await a.routes.fetch(root); return 'routes' in g && g.routes.length ? g : undefined; }, 'routes', 120_000);
      const cli = await a.routes.fetchCli(root);
      r.routes = { lsp: lsp.routes.length, cli: 'routes' in cli ? cli.routes.length : cli.error };
      if (r.routes.lsp !== r.routes.cli) throw new Error(`server lists ${r.routes.lsp}, CLI ${r.routes.cli}`);
    });

    await soft('tests', async () => {
      await a.tests.discoverAll();
      const leaves: string[] = [];
      const walk = (items: vscode.TestItemCollection) => items.forEach(i => (i.children.size ? walk(i.children) : leaves.push(i.id)));
      walk(a.tests.controller.items);
      r.tests.discovered = leaves.length;
      const cts = new vscode.CancellationTokenSource();
      const outs = await a.tests.execute(new vscode.TestRunRequest(), 'run', cts.token);
      r.tests.outcome = outs.map(o => `${o.kind}${o.summary ? ` (${o.summary})` : ''}`).join('; ');
      const results = outs.flatMap(o => o.results);
      r.tests.results = results.length;
      r.tests.failed = results.filter(x => !x.ok).map(x => `${x.id.split('\0').slice(1).join(' ')}: ${x.message ?? ''}`);
      if (outs.some(o => o.kind !== 'results')) throw new Error(`run ended as ${r.tests.outcome}`);
      if (r.tests.results !== r.tests.discovered) throw new Error(`discovered ${r.tests.discovered}, results for ${r.tests.results}`);
    });

    await soft('generators', async () => {
      // the first page module: the generators that apply at its first line
      const page = r.files.map(f => join(root, f.file)).find(f => /^page\b/m.test(readFileSync(f, 'utf8')));
      if (!page) throw new Error('no page module');
      const client = await a.clients.forUri(vscode.Uri.file(page));
      const gens = await client!.sendRequest<{ here?: boolean }[]>('alder/generators', {
        textDocument: { uri: vscode.Uri.file(page).toString() }, position: { line: 0, character: 0 },
      });
      r.generators = { file: relative(root, page), count: gens.length, here: gens.filter(g => g.here).length };
      if (!gens.length) throw new Error('the server lists no generators');
    });

    await soft('scratch', async () => {
      const t0 = Date.now();
      const ed = await a.scratch.open();
      const doc = ed!.document;
      const hints = await until(async () => {
        const hs = await vscode.commands.executeCommand<vscode.InlayHint[]>('vscode.executeInlayHintProvider', doc.uri, new vscode.Range(0, 0, doc.lineCount, 0));
        const ls = (hs ?? []).map(h => (typeof h.label === 'string' ? h.label : h.label.map(p => p.value).join('')));
        return ls.includes('⇒ 2 : Int') ? ls : undefined;
      }, 'the template watch ⇒ 2 : Int', 600_000);
      r.scratch = { ms: Date.now() - t0, hints };
    });

    const out = process.env.ALDER_DOGFOOD_OUT!;
    mkdirSync(dirname(out), { recursive: true });
    writeFileSync(out, JSON.stringify(r, null, 2));
    assert.deepEqual(r.failures, [], `see ${out}`);
  });
});
```
